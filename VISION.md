# МотоХаб — видение продукта

## Что такое МотоХаб

МотоХаб — локальный помощник мотоциклиста.

Он помогает быстро найти ответ на практический вопрос:

- где обслужить или починить мотоцикл;
- где поменять резину;
- где купить экипировку, запчасти и расходники;
- где оформить страховку;
- где хранить мотоцикл зимой;
- куда поехать;
- какие события проходят рядом;
- где тренироваться;
- как разобраться в обслуживании, безопасности и мотоциклетной жизни.

Первая территория запуска — Смоленск и Смоленская область.

## Главное обещание

Пользователь должен быстро получить полезный ответ, а не разбираться в сложной структуре приложения.

Если пользователь знает свой вопрос, он использует поиск.

Если пользователь хочет изучить доступные возможности, он открывает разделы.

Оба пути должны вести к одним и тем же конечным карточкам, материалам, маршрутам, местам и событиям.

## Что мы делаем

Мы создаём:

- удобный поиск по практическим вопросам;
- структурированный каталог полезных мест;
- короткие и понятные материалы;
- маршруты и идеи для поездок;
- события и информацию о мотосообществе;
- материалы по навыкам и безопасности.

## Что мы не делаем

Мы не создаём:

- ещё одну социальную сеть;
- огромную энциклопедию;
- бесконечную ленту;
- форум;
- приложение только для учеников MG67;
- приложение только для новичков;
- сложную CRM мотошколы;
- набор функций без понятной пользовательской пользы.

## Основные принципы

### Практическая польза

Каждая функция должна отвечать на вопрос:

«Какую реальную проблему мотоциклиста она решает?»

Если ответа нет, функция не добавляется.

### Простота

Пользователь не должен изучать интерфейс.

Основные действия должны быть понятны за несколько секунд.

### Поиск и разделы — разные сценарии

Поиск:

- используется для конкретного вопроса;
- выдаёт релевантные результаты;
- не показывает случайные материалы.

Разделы:

- позволяют спокойно изучать приложение;
- имеют собственную навигацию;
- не перенаправляют пользователя в поиск после каждого нажатия.

### Честность

Мы не публикуем:

- выдуманные отзывы;
- неподтверждённые рейтинги;
- фиктивные рекомендации;
- непроверенные организации под видом проверенных;
- опасные советы без проверки.

### Развитие постепенно

Сначала создаётся качественный MVP для Смоленской области.

Затем:

- тестирование;
- обратная связь;
- исправление проблем;
- наполнение;
- официальный запуск;
- возможное расширение в другие регионы.

## Критерий успеха MVP

MVP считается успешным, если пользователь может:

1. открыть приложение;
2. понять, чем оно помогает;
3. найти нужную информацию;
4. открыть карточку;
5. сохранить её;
6. вернуться позже;
7. использовать приложение без помощи автора.

Даже небольшое количество реальных пользователей является полезным результатом, если приложение действительно помогает им.
